# Privacy Policy Pages

앱 스토어용 개인정보처리방침을 호스팅하는 정적 사이트입니다.

## URL

- 목록: https://beggu84.github.io/
- 앱별 방침: https://beggu84.github.io/privacy/{앱-슬러그}.html

## 새 앱 방침 추가

1. `privacy/sample-app.html`을 복사해 `privacy/{앱-슬러그}.html`로 저장합니다.
2. 파일 안의 `[앱 이름]`, `[문의 이메일]` 등 플레이스홀더를 실제 내용으로 바꿉니다.
3. `index.html` 목록에 링크를 추가합니다.
4. 커밋 후 `main`(또는 `master`)에 푸시하면 GitHub Pages에 반영됩니다.
